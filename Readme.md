# Task Manager A responsive task manager with add/edit/delete, labels, priorities, filtering, search, and local backup/restore — built with vanilla HTML, CSS, and JavaScript. ## Features - Add, edit, and delete tasks - Name, date/time, label, and priority per task - Mark tasks complete - Filter by All / Active / Completed - Real-time search - Dark / light / system theme - Export a readable .txt report - Backup and restore tasks as JSON - Data persists locally via localStorage - Tasks grouped into Overdue / Today / Upcoming / Completed, sorted by deadline or priority - Relative due times like "in 2 h" or "overdue by 1 day", refreshed every 30 seconds - Daily progress line ("4 of 9 done today") with a progress bar ## Tech stack HTML, CSS, JavaScript (no frameworks), Lucide icons, Inter font ## Live demo https://ahmedalsoufi14-4r4s.github.io/TaskManager-app/
